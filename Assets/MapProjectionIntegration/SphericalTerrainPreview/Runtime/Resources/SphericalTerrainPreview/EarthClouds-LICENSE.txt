Based on NASA imagery; an artistic global weather composite, not live weather.
The source JPEG is unchanged. Unity imports it as a linear BC4 cloud-coverage
texture with mipmaps. Game shaders filter coverage, remap density, animate
latitude-dependent winds and add smooth cloud lighting to a single cloud layer.
